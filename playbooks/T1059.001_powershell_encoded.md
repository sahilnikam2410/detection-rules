# Playbook: PowerShell encoded command (T1059.001)

| | |
|---|---|
| **Triggers** | Wazuh `100230` (draft) · Sigma `PowerShell Encoded Command` · Splunk [`win_powershell_encoded_command_t1059.spl`](../queries/splunk/win_powershell_encoded_command_t1059.spl) |
| **ATT&CK** | [T1059.001 PowerShell](https://attack.mitre.org/techniques/T1059/001/), Execution |
| **Default severity** | High. **Critical** if the decoded command downloads, injects or disables security tooling |
| **Target time to triage** | 15 minutes |

## 1. Decode it first

The encoded blob is base64 of **UTF-16LE** text. Decode it on the analyst machine, **never on the endpoint**, and never run the output.

```powershell
[Text.Encoding]::Unicode.GetString([Convert]::FromBase64String('<BLOB>'))
```

```bash
echo '<BLOB>' | base64 -d | iconv -f UTF-16LE -t UTF-8
```

In CyberChef: *From Base64 → Decode text (UTF-16LE)*.

## 2. Read the decoded command

| Red flags | Why they matter |
|---|---|
| `IEX`, `Invoke-Expression`, `DownloadString`, `DownloadFile`, `Net.WebClient`, `Invoke-WebRequest` | Download-and-run |
| `-w hidden`, `-nop`, `-ep bypass` next to the encoding | Built to stay out of sight |
| `FromBase64String` inside the decoded text | Encoding inside encoding |
| `Set-MpPreference -Disable…`, `Add-MpPreference -ExclusionPath` | Turning off Defender |
| `Reflection.Assembly`, `VirtualAlloc` | In-memory loading |

## 3. Context

1. **Parent process** (Sysmon 1 `ParentImage`): `winword.exe`, `excel.exe`, `outlook.exe`, `mshta.exe` or `wscript.exe` as parent is **malicious until proven otherwise** (phishing, [T1566](https://attack.mitre.org/techniques/T1566/)).
2. **User:** interactive user, SYSTEM, or a service account?
3. **Network:** any Sysmon 3 connection from that PowerShell process in the next minutes? To where?
4. **Spread:** the same command line on other hosts?

```spl
index=sysmon EventCode=1 Image="*\\powershell.exe" CommandLine="*<first 20 chars of BLOB>*"
| stats count values(host) values(User) values(ParentImage) by CommandLine
```

## 4. Decide

| Finding | Verdict |
|---|---|
| Parent is SCCM / Intune / known RMM agent, decoded text is an inventory or config script, same on many managed hosts | **Benign**: document it, request an exclusion by parent + hash |
| Admin ran it by hand and confirms it | **Benign TP**: note it and ask them to use signed scripts |
| Any red flag from step 2, or an Office / script-host parent | **True positive**: contain and escalate |

## 5. Contain and escalate

1. Isolate the host (EDR network containment, or disconnect it).
2. Block any domain or IP in the decoded command at the proxy and firewall.
3. **Escalate to L2** with: decoded command, parent chain, user, first-seen time, hosts affected.
4. Do **not** kill the process before memory is captured if L2 wants forensics. Ask first.

## Tuning

Exclude by **parent image + signer**, not by user. Never exclude on command-line text alone, because attackers copy legitimate tooling's arguments.
